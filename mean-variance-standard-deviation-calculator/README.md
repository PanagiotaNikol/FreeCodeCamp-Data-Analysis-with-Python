# Mean-Variance-Standard-Deviation Calculator

## Overview

This project is part of the freeCodeCamp Data Analysis with Python curriculum. It implements a statistical calculator that uses NumPy to analyze a list of nine numerical values arranged into a 3×3 matrix.

The calculator computes statistical measures for each column, each row, and the entire matrix.

## Features

- Calculates the mean.
- Calculates the variance.
- Calculates the standard deviation.
- Finds the maximum and minimum values.
- Calculates the sum of values.
- Returns the results as a dictionary containing statistics for rows, columns, and the entire matrix.

## Technologies Used

- **Python** — Programming language.
- **NumPy** — Numerical computing and statistical calculations.

## How to Run

1. Make sure Python and NumPy are installed.
2. Run the following command to install NumPy if needed:

   `pip install numpy`

3. Execute the Python script:

   `python mean_var_std.py`

The `calculate()` function accepts a list of nine numbers and raises a `ValueError` if the list does not contain exactly nine elements.

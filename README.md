# FreeCodeCamp — Data Analysis with Python

This repository contains five Python projects completed as part of the freeCodeCamp Data Analysis with Python curriculum.

The projects focus on data analysis, statistical calculations, data visualization, and linear regression using Python.

## Projects

### 1. Mean-Variance-Standard-Deviation Calculator
Uses NumPy to calculate statistical measures, including mean, variance, standard deviation, maximum, minimum, and sum across rows, columns, and the entire matrix.

**Technologies:** Python, NumPy

### 2. Demographic Data Analyzer
Uses Pandas to analyze demographic data and explore relationships between education, income, working hours, and occupation.

**Technologies:** Python, Pandas

### 3. Medical Data Visualizer
Explores medical examination data and creates visualizations to examine health-related variables and correlations.

**Technologies:** Python, Pandas, Matplotlib, Seaborn

### 4. Page View Time Series Visualizer
Analyzes daily freeCodeCamp forum page views and creates line, bar, and box plots to explore trends over time.

**Technologies:** Python, Pandas, Matplotlib, Seaborn

### 5. Sea Level Predictor
Analyzes historical sea level measurements and uses linear regression to estimate future sea level changes through 2050.

**Technologies:** Python, Pandas, Matplotlib, SciPy

## Skills Demonstrated

- Data analysis with Pandas
- Statistical calculations with NumPy
- Data visualization with Matplotlib and Seaborn
- Exploratory data analysis
- Linear regression and trend prediction
- Python programming

## Note

The Python scripts for projects that use external datasets require their corresponding CSV files to run. These datasets are not currently included in this repository.

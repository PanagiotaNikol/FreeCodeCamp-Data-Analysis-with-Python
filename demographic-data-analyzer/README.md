# Demographic Data Analyzer

## Overview

This project is part of the freeCodeCamp Data Analysis with Python curriculum. It uses the Pandas library to explore demographic data from the 1994 Census database.

The goal is to analyze the population's characteristics and investigate relationships between education, income, working hours, occupation, and country of origin.

## Features

- Calculates the number of people in different racial groups.
- Determines the average age of men.
- Calculates the percentage of people with a Bachelor's degree.
- Compares income levels based on educational attainment.
- Identifies the minimum number of hours worked per week.
- Examines income among people working the minimum number of hours.
- Identifies the country with the highest percentage of people earning more than $50,000.
- Finds the most common occupation among people earning more than $50,000 in India.

## Technologies Used

- **Python** — Programming language.
- **Pandas** — Data manipulation and analysis.

## Dataset

The project requires the `adult.data.csv` dataset, which must be available in the appropriate project directory.

## How to Run

1. Install Python and Pandas:

   `pip install pandas`

2. Place `adult.data.csv` in the project directory.
3. Run the script:

   `python demographic_data_analyzer.py`

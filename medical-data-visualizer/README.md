# Medical Data Visualizer

## Overview

This project is part of the freeCodeCamp Data Analysis with Python curriculum. It uses medical examination data to explore health-related variables and investigate relationships between different health indicators.

The project focuses on data preparation, exploratory data analysis, and visualization.

## Features

- Loads and processes medical examination data using Pandas.
- Creates categorical plots to compare health-related characteristics.
- Examines variables such as body mass index, cholesterol, glucose, smoking, alcohol consumption, physical activity, and cardiovascular disease.
- Generates a correlation heatmap to explore relationships between numerical variables.
- Prepares the data for visualization and removes specified outliers when required by the analysis.

## Technologies Used

- **Python** — Programming language.
- **Pandas** — Data processing and analysis.
- **Matplotlib** — Plotting and visualization.
- **Seaborn** — Statistical visualizations.

## Dataset

The project requires the `medical_examination.csv` file.

## How to Run

1. Install the required libraries:

   `pip install pandas matplotlib seaborn numpy`

2. Place `medical_examination.csv` in the appropriate project directory.
3. Run the script:

   `python medical_data_visualizer.py`

The script generates two visualizations: `catplot.png` and `heatmap.png`.
